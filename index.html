Frequently Asked Questions

Is it safe?
Yes. Strickzzz is built with transparency as a core value. It doesn't use root, doesn't touch game code, and only uses standard Android APIs to gather telemetry data.
Will it get me banned?
Strickzzz never touches game files, memory or traffic and never uses root. It acts as an external monitor. However, no app can promise what a publisher will decide. We recommend using Safe Mode (coming soon) for high-stakes tournaments.
Is the FPS real?
Most apps use average polling which is inaccurate. In Enhanced mode, Strickzzz reads actual frame timings from the display buffer (via wireless debugging/Shizuku) to give you true 1% lows and stutter detection.
Where is my data stored?
Exclusively on your device. Strickzzz has no backend, no analytics, and no tracking. All performance logs are kept locally and can be deleted by you at any time.
